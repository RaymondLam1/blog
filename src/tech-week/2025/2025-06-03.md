## 2025-06-03Tech Time

### Apache calcite

::: info
Apache Calcite 是一个动态数据管理框架，提供了： SQL 解析 、 SQL 校验 、 SQL 查询优化 、 SQL 生成 以及 数据连接查询 等典型数据库管理功能。

https://github.com/apache/calcite/
:::

### Apache seatunnel

::: info
SeaTunnel是一个非常易用、超高性能的分布式数据集成平台，支持实时海量数据同步。 每天可稳定高效同步数百亿数据，已被近百家企业应用于生产。

https://github.com/apache/seatunnel
:::
